# 实验流程编写与安全复核工具

面向研究人员和实验室安全复核人员的纯前端工作台。实验步骤、复核批注和冻结版本均保存在浏览器本机，可离线编辑。

## 功能

- 按步骤维护名称、目的、材料、设备、用量、预计时间、安全说明、预期结果和依赖关系。
- 危险项逐项登记，每项单独填写控制措施与残余风险；新增或改写危险项后，该项原有控制与签署立即失效。
- 添加、复制、删除、上下移动实验步骤，通过复选框建立前置依赖。
- 修改步骤后自动计算全部下游步骤，提醒受影响的后续步骤和已确认内容。
- 提交复核后，复核人可逐条添加批注、标记解决，并对每个危险项分别签署结论（接受残余风险 / 要求改进）。
- 危险项缺少控制措施、安全说明或尚未复核签署时，步骤不能确认；冻结入口会逐项指明卡在哪几项。
- 所有步骤确认且危险项控制与签署完整后冻结版本；冻结后只能从该版本创建修订稿，修订稿需重新签署。
- 保存多个完整版本快照，比较步骤新增、删除及材料、用量、危险项控制、残余风险、签署与依赖等变化。
- 旧版数据（整段控制措施）在载入时自动迁移为逐项结构，整段控制措施保留到每个危险项。
- 完整撤销重做、本地自动保存和 `Ctrl/Cmd+S` 手动保存。

## 技术栈

- React 19 + TypeScript
- Vite
- Blueprint UI (`@blueprintjs/core`、`@blueprintjs/icons`)
- 浏览器 localStorage
- Nginx 静态部署

## 本地开发

```bash
npm install
npm run dev
```

开发服务器监听 `5173`，宿主端口仅由部署映射，源码未写入 `10027`。

## 生产构建

```bash
npm install
npm run build
```

构建产物位于 `dist`。

## Docker

```bash
docker build -t sologsb-1027 .
docker run --rm -p 10027:80 sologsb-1027
```

容器内 Nginx 监听 `80`，访问 `http://localhost:10027`。实验数据仅保存在当前浏览器。

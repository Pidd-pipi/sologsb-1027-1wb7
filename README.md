# 实验流程编写与安全复核工具

面向研究人员和实验室安全复核人员的纯前端工作台。实验步骤、复核批注和冻结版本均保存在浏览器本机，可离线编辑。

## 功能

- 按步骤维护名称、目的、材料、设备、用量、预计时间、危险项、安全说明、预期结果和依赖关系。
- 危险项逐项对应控制措施与残余风险，复核人可对每个危险项分别签署「控制有效 / 控制不足退回」。
- 新增或改写危险项后，该项原有控制措施与签署立即失效（残余风险保留），需重新填写并复核。
- 添加、复制、删除、上下移动实验步骤，通过复选框建立前置依赖。
- 修改步骤后自动计算全部下游步骤，提醒受影响的后续步骤和已确认内容。
- 任一危险项缺少控制措施、尚未复核签署或被退回时，步骤不能确认；冻结入口（页头、提交与冻结、复核决定、冻结检查）逐组列出卡在哪一步哪一项。
- 提交复核后，复核人可逐条添加批注、标记解决、确认或退回。
- 所有步骤确认、危险项逐项签署通过且安全信息完整后冻结版本；冻结后只能从该版本创建修订稿。
- 旧数据按整段控制措施自动迁移到首个危险项；保存多个完整版本快照，并逐项比较危险项新增、删除、改名及控制措施、残余风险、签署结论等变化。
- 完整撤销重做、本地自动保存和 `Ctrl/Cmd+S` 手动保存，逐项管控结果一并保留。

## 技术栈

- React 19 + TypeScript
- Vite
- Blueprint UI (`@blueprintjs/core`、`@blueprintjs/icons`)
- 浏览器 localStorage
- Nginx 静态部署

## 本地开发

```bash
npm install
npm run dev
```

开发服务器监听 `5173`，宿主端口仅由部署映射，源码未写入 `10027`。

## 生产构建

```bash
npm install
npm run build
```

构建产物位于 `dist`。

## Docker

```bash
docker build -t sologsb-1027 .
docker run --rm -p 10027:80 sologsb-1027
```

容器内 Nginx 监听 `80`，访问 `http://localhost:10027`。实验数据仅保存在当前浏览器。
